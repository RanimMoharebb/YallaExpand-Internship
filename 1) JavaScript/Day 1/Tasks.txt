Task 1:
--- curry(fn)
Implement a curry function that transforms a function of N arguments into a series of function calls, each taking one or more arguments, until all N arguments are supplied — then it invokes the original function.
js

EX:-

function curry(fn) {
  // your implementation
}

function sum(a, b, c) {
  return a + b + c;
}

const curriedSum = curry(sum);

curriedSum(1)(2)(3);     // 6
curriedSum(1, 2)(3);     // 6
curriedSum(1)(2, 3);     // 6
curriedSum(1, 2, 3);     // 6

3- Handle non-promise values in the array (e.g. plain numbers/strings) by treating them as already-resolved.
4- Resolve immediately with [] if given an empty array.

EX:- 

function myPromiseAll(promises) {
  // your implementation
}

myPromiseAll([
  Promise.resolve(1),
  2,
  new Promise((res) => setTimeout(() => res(3), 100)),

Task 3:
--- Implement myMap as a method on Array.prototype, matching native map behavior as closely as possible.

Requirements:

1- Callback signature must be (element, index, array).
2- Support an optional second argument, thisArg, that sets this inside the callback.
3- Must return a new array — don't mutate the original.
4- Must correctly skip holes in sparse arrays (e.g. [1, , 3] — native map does not invoke the callback for empty slots, but still leaves a hole in the result).
5- Should work on any array, with any callback, not just the example below.

EX:-

[1, 2, 3].myMap((x, i, arr) => x * 2);
// [2, 4, 6]

[1, 2, 3].myMap(function(x) {
  return x + this.offset;
}, { offset: 10 });
// [11, 12, 13]

[1, , 3].myMap(x => x * 2);
// [2, <1 empty item>, 6]
